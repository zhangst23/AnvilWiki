## How to redeem a HANDS OVER code

Codes are redeemed inside the game, not on this page. The exact menu path moves between platforms and builds, so use the redeem entry in your own client instead of copying a click path from an older video.

1. Launch HANDS OVER and reach the main menu or your profile screen.
2. Open the redeem or code entry point in that menu.
3. Type the code exactly as it is written — codes are normally case-sensitive and reject stray spaces.
4. Confirm the submission, then check your inventory or rewards screen for the item.

Some rewards are credited to the account rather than to a single character, so make sure you are signed in with the account you actually play on before you redeem. If the redeem screen rejects a code outright, the code itself is the likely problem — see the next section.

## Why a code might not work

- **It expired.** Expiry dates are set by the developer and are not always announced in advance.
- **It was already used.** Most codes are one per account, so a second attempt on the same account fails.
- **It is region or platform locked.** A code handed out for one storefront does not always redeem on another.
- **It was retyped.** A trailing space or the wrong capitalisation is enough to invalidate an otherwise live code.

If a code fails on all four counts, treat it as unverified and do not keep retrying. This page does not list codes that have not been confirmed, which is why the active list stays empty rather than padded with guesses.
