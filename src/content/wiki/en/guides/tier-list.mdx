This page is the working surface for a HANDS OVER tier list, kept public as a draft so the structure is visible while the testing pass is still running. It deliberately shows no rankings: a tier list is only worth reading if each row was measured in the live build, and nothing has been measured yet. Once a pick has been played enough to justify a placement, its row gets a real reason and the draft flag comes off.

## How entries will be ranked

Three questions decide every placement, in this order:

1. **Does it change the outcome of a trial?** A pick that only shifts numbers sits below one that changes whether the team survives.
2. **How forgiving is it when someone misplays?** A co-op game punishes one weak link, so a pick that still works after a mistake outranks a stronger pick that collapses.
3. **Does it hold up when the team is bad?** Five-player co-op means a pick that needs a coordinated team is worth less than one that carries a disorganised group.

Anything that fails all three is not ranked at all; it gets a note in the section below instead of a tier.

## What is still missing

- **The pick list itself.** Every row currently reads [待补充] because the character and gear list has not been handed over yet.
- **Your reasoning, one line per row.** The table keeps a single "why it sits here" column on purpose — that column is the whole value of the page.
- **Contested picks.** Any placement that splits opinion will be pulled out under the callout above with the reason it is argued about, instead of being silently averaged into a tier.
- **An in-game test date.** The header date tracks when this page was edited, not when anything was verified; the two are only the same once testing actually happens.

## What this page will not do

It will not fill a tier with a guess to look complete. A short list of five measured placements is more useful than thirty invented ones, and it is far less likely to get a reader killed in a trial. The same rule already governs the [codes page](/codes/): nothing is listed as working until it is confirmed.

When the list is ready to be tested, the picks will be checked against the live build, each row will get its one-line verdict, and the draft flag will be removed so the page can be indexed alongside the rest of the [guides index](/guides/). Questions about the site itself are answered on the [FAQ page](/faq/).
